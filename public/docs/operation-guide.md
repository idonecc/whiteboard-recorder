## Getting Started

### First Launch

1. Open Whiteboard Recorder in your browser
2. Grant camera/microphone permissions when prompted
3. Welcome modal appears – click "Get Started" to begin

### Basic Workflow

```
Prepare Content → Add Slides → Configure Recording → Record → Export
```

**Estimated Time**: 10-30 minutes per video

## Whiteboard Basics

### Drawing Tools

| Tool | Shortcut | Description |
|------|----------|-------------|
| **Selection** | `V` or `1` | Select and move elements |
| **Rectangle** | `R` or `2` | Draw rectangles |
| **Diamond** | `D` or `3` | Draw diamonds |
| **Ellipse** | `O` or `4` | Draw circles/ellipses |
| **Arrow** | `A` or `5` | Draw arrows |
| **Line** | `L` or `6` | Draw straight lines |
| **Freedraw** | `P` or `7` | Hand-drawn lines |
| **Text** | `T` or `8` | Add text |
| **Image** | - | Insert images |
| **Eraser** | `E` or `9` | Erase elements |

### Canvas Navigation

- **Pan**: Hold `Space` + drag, or use mouse wheel button
- **Zoom**: `Ctrl/Cmd` + Mouse wheel, or pinch gesture
- **Fit to Screen**: `Ctrl/Cmd + 0`
- **Reset Zoom**: `Ctrl/Cmd + 1`

### Element Operations

- **Duplicate**: Select element → `Ctrl/Cmd + D`
- **Delete**: Select element → `Delete` or `Backspace`
- **Group**: Select multiple → `Ctrl/Cmd + G`
- **Ungroup**: Select group → `Ctrl/Cmd + Shift + G`
- **Bring to Front**: `Ctrl/Cmd + ]`
- **Send to Back**: `Ctrl/Cmd + [`

### Color & Style

Click any element to open the properties panel:
- **Stroke Color**: Outline color
- **Background**: Fill color
- **Stroke Width**: Line thickness
- **Stroke Style**: Solid, dashed, dotted
- **Sloppiness**: Hand-drawn effect intensity
- **Edge**: Sharp or round
- **Fill**: Solid, hachure, cross-hatch

## Slides System

### What are Slides?

Slides organize your whiteboard into **recording viewports**. Each slide defines a rectangular area to be recorded.

### Creating Slides

1. Click **Slides** button (right side toolbar)
2. Click **+ Add Slide** 
3. Draw a rectangle on the canvas
4. Repeat to create multiple slides

**Tips**:
- All slides share the same aspect ratio (set during first slide creation)
- Slides appear as thumbnails in the slide strip
- Click thumbnail to navigate to that slide

### Navigating Slides

- **Next Slide**: `→` (Right arrow) or click next thumbnail
- **Previous Slide**: `←` (Left arrow) or click previous thumbnail
- **Delete Slide**: Hover thumbnail → click trash icon

### During Recording

- Use `←` `→` to switch slides while recording
- Canvas animates smoothly between slides
- Current slide highlighted in strip

## Recording Setup

### Accessing Settings

Click **⚙️ Settings** button (top toolbar) to open recording settings panel.

### Aspect Ratio

Choose recording dimensions:

| Ratio | Use Case | Resolution (example) |
|-------|----------|---------------------|
| **16:9** | YouTube, tutorials | 1920×1080 |
| **4:3** | Classic, presentations | 1024×768 |
| **3:4** | Instagram, stories | 1080×1440 |
| **9:16** | TikTok, vertical video | 1080×1920 |
| **1:1** | Square posts | 1080×1080 |
| **Custom** | Any size | Your choice |

**Important**: Choose aspect ratio **before** creating slides.

### Background

1. Open **Settings** → **Recording** tab
2. Click background thumbnail
3. Choose from presets or upload custom image

**Background Types**:
- **Solid Colors**: Clean, minimal
- **Gradients**: Modern, dynamic
- **Custom Image**: Brand backgrounds

### Canvas Padding

Add space around whiteboard content:
- Adjust **Padding** slider (0-200px)
- Useful for adding visual breathing room

## Webcam Configuration

### Enable Webcam

1. Click **Settings** → **Camera** tab
2. Click **Enable Camera**
3. Grant browser permissions if prompted
4. Webcam bubble appears on canvas

### Camera Settings

**Video Source**
- Select camera from dropdown
- Supports multiple cameras (switch anytime)

**Shape**
- **Circle**: Friendly, casual
- **Square**: Professional, formal

**Size**
- Drag slider to adjust bubble size
- Range: 10% - 30% of viewport

**Position**
- Drag bubble to any corner
- Snaps to safe zones

### Background Removal (Experimental)

1. Enable **Remove Background** toggle
2. Webcam processes video in real-time
3. Requires modern browser (Chrome 90+)

**Note**: Background removal may impact performance on slower devices.

## Teleprompter

### Opening Teleprompter

Click **📜 Teleprompter** button (top toolbar)

### Modes

**Full Mode** (default)
- Large overlay panel
- Word-by-word highlighting
- Auto-scroll with voice following

**Lightweight Mode**
- Small floating window
- Minimal UI
- Draggable position

Toggle with **Lightweight Mode** checkbox.

### Using Teleprompter

1. Paste script into text area
2. Enable **Highlight Words** (optional)
3. Enable **Voice Following** (optional)
   - Requires microphone permission
   - Scrolls automatically as you speak
4. Click **▶️ Start** to begin scrolling
5. Adjust **Speed** slider during playback

### Voice Following

**How it works**:
- Microphone detects speech
- Highlights current word based on audio
- Scrolls to keep current word visible

**Best Practices**:
- Speak clearly and at steady pace
- Pause briefly between sentences
- Test before recording

## Recording & Export

### Starting Recording

1. Complete content preparation
2. Click **● Record** button (top toolbar)
3. Choose aspect ratio (if first time)
4. Review settings in preview modal
5. Click **Start Recording**

### During Recording

**Controls**:
- **⏸️ Pause**: Pause recording (resume with same button)
- **⏹️ Stop**: End recording and proceed to export
- **Navigate Slides**: Use `←` `→` keys

**On-Screen Indicators**:
- Red border around recording area
- Timer showing elapsed time
- Slide counter (e.g., "2 / 5")

### Export Options

After stopping, export modal appears:

1. **Preview**: Watch recorded video
2. **Export Settings**:
   - Format: MP4 (H.264)
   - Quality: High (default)
3. **Download**: Click download button
4. **Retry**: Discard and record again

**File Naming**: `whiteboard-recording-YYYY-MM-DD-HHmmss.mp4`

### Post-Production Tips

Recorded MP4 works with all major video editors:
- **Adobe Premiere** / **Final Cut Pro**: Professional editing
- **DaVinci Resolve**: Free, powerful
- **iMovie** / **Windows Video Editor**: Simple cuts

## Troubleshooting

### Camera/Mic Not Working

**Symptoms**: "Permission denied" error or blank camera

**Solutions**:
1. **Grant Browser Permissions**
   - Click lock icon in address bar
   - Allow camera and microphone
   - Refresh page

2. **Check System Settings** (macOS)
   - System Settings → Privacy & Security
   - Camera / Microphone → Enable for your browser

3. **Try Different Browser**
   - Chrome 90+ recommended
   - Edge 90+ also works well

4. **Check Physical Devices**
   - Is camera covered?
   - Is mic muted?
   - Try different USB port

### Recording Export Failed

**Symptoms**: "Export failed" error or corrupted video

**Solutions**:
1. **Use Even Dimensions**
   - H.264 requires even width/height
   - Avoid custom sizes like 1921×1081

2. **Free Disk Space**
   - Ensure 1GB+ free space
   - Long recordings need more space

3. **Update Browser**
   - Chrome/Edge 90+ required
   - Check for updates

4. **Disable Extensions**
   - Ad blockers may interfere
   - Try incognito mode

### Slides Not Switching

**Symptoms**: Arrow keys don't change slides

**Solutions**:
1. Ensure slides are created (check slide strip)
2. Click canvas first (focus issue)
3. During recording, slides animate smoothly (not instant)

### Teleprompter Voice Following Broken

**Symptoms**: Highlighting doesn't match speech

**Solutions**:
1. Check microphone permissions
2. Speak clearly and steadily
3. Adjust speed manually if needed
4. Disable voice following, use manual scroll

### Performance Issues

**Symptoms**: Lag, dropped frames, choppy recording

**Solutions**:
1. **Close Other Apps**
   - Free up RAM
   - Close unused browser tabs

2. **Disable Background Removal**
   - Settings → Camera → Remove Background off

3. **Lower Canvas Complexity**
   - Simplify drawings
   - Use fewer elements per slide

4. **Use Lower Resolution**
   - 1280×720 instead of 1920×1080

### Mobile Not Working

**Expected Behavior**: Mobile shows landing page (desktop-only tool)

Whiteboard Recorder requires desktop browser for full functionality.

## Best Practices

### Content Preparation

1. **Script First**: Write script before drawing
2. **Storyboard**: Plan slide sequence
3. **Test Run**: Practice once without recording
4. **Keep It Simple**: Fewer elements = clearer message

### Recording Tips

1. **Good Lighting**: Face camera with light source in front
2. **Quiet Environment**: Minimize background noise
3. **Steady Pace**: Don't rush, audience needs time to process
4. **Use Teleprompter**: Maintain eye contact with camera
5. **Pause Between Slides**: Give viewers transition time

### Technical Setup

1. **Use HTTPS**: Required for camera/mic (or use localhost)
2. **Wired Internet**: Avoid Wi-Fi interruptions
3. **Close Background Apps**: Free up system resources
4. **Test First**: 30-second test recording before full take

### Editing Workflow

1. **Record Segments**: Break long videos into multiple recordings
2. **Edit in Post**: Combine clips in video editor
3. **Add Music**: Background music improves engagement
4. **Captions**: Add subtitles for accessibility
